## 👋 About Me

I'm a third-year **Computer Engineering** student at **Sakarya University**.

During my internship at **GBB Bilişim**, I built the backend of **kARTVİN**, a public transportation app for the city of Artvin, as a RESTful API with **Laravel** and **PostgreSQL**. Now I'm taking that software engineering foundation into **AI**, with a focus on **generative AI** and **large language models**.

## 🚀 Featured Project

### [kARTVİN Backend](https://github.com/sekooo-ctrl/kartvin-backend) · Public Transportation API

`Laravel 13` `PHP 8.3` `PostgreSQL` `Sanctum` `PHPUnit`

- **30+ REST endpoints** consumed by a Flutter mobile app
- **Route planner** that finds direct and transfer connections and estimates travel time
- **Live bus tracking** simulation, **QR fare payment** and a **green-point reward** system
- Token-based auth and **18 feature test suites**
